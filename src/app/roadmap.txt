5. BACKEND ROADMAP (NODE.JS, EXPRESS & PRODUCTION API)
================================================================================
To replace ShopStore.tsx with a production-grade backend:

1. Server Fundamentals (Node.js & Express.js):
   - Node.js Runtime architecture.
   - Express app initialization, JSON body parsing middleware (express.json()).
   - CORS configuration (cors package) for mobile/web requests.
2. MVC Architecture:
   - Routes: /api/products, /api/auth, /api/cart, /api/orders.
   - Controllers: productController.js, authController.js, orderController.js.
   - Models: Data schemas.
   - Middlewares: Authentication checks, validation.
3. Database (Choose One):
   - Option A: PostgreSQL with Prisma ORM (Recommended for E-Commerce / Financial data).
   - Option B: MongoDB with Mongoose (Flexible NoSQL document model).
   - Database operations: CRUD (Create, Read, Update, Delete), Indexing, Foreign Keys.
4. Authentication & Security:
   - Password Hashing: bcryptjs (hash passwords before saving to DB).
   - JWT (JSON Web Tokens): jsonwebtoken package. Sign token on login, verify in middleware.
   - Authorization Middleware: Protect admin routes (verifyAdmin middleware).
5. Input Validation:
   - Zod or Joi schema validation (Ensure emails, prices, IDs are valid before reaching DB).
6. Environment Variables:
   - dotenv package (.env file for DB_URL, JWT_SECRET, PORT).
7. Deployment:
   - Backend Hosting: Render, Railway, AWS EC2, or DigitalOcean.
   - Database Hosting: Supabase / Neon (PostgreSQL) or MongoDB Atlas.

6. REST API BLUEPRINT FOR SHOPNEST
================================================================================
[AUTH MODULE]
- POST /api/auth/register    -> Register user, return JWT token.
- POST /api/auth/login       -> Authenticate credentials, return JWT + User role.
- GET  /api/auth/profile     -> Get logged-in user profile (Protected route).
- PUT  /api/auth/profile     -> Update name, phone, address (Protected route).

[PRODUCT & CATALOG MODULE]
- GET    /api/products           -> Get all products (with search, category, page query params).
- GET    /api/products/:id       -> Get single product details + reviews.
- POST   /api/products           -> (Admin Only) Create new product.
- PUT    /api/products/:id       -> (Admin Only) Update stock, price, discount.
- DELETE /api/products/:id       -> (Admin Only) Delete product.
- GET    /api/categories         -> Get categories list with icons.

[CART & WISHLIST MODULE]
- GET    /api/cart               -> Get user's active cart.
- POST   /api/cart/add           -> Add item with variant (color, size, quantity).
- PUT    /api/cart/update        -> Increment/Decrement item quantity.
- DELETE /api/cart/remove/:id    -> Remove item from cart.
- POST   /api/coupons/apply      -> Validate promo code (e.g. WELCOME10) and calculate discount.

[ORDER & PAYMENT MODULE]
- POST   /api/orders/create      -> Create order from cart items + address + payment mode.
- GET    /api/orders/my-orders   -> Get customer order history.
- GET    /api/orders/:id         -> Get specific order timeline and tracking.
- GET    /api/admin/orders       -> (Admin Only) Get all customer orders.
- PATCH  /api/admin/orders/:id   -> (Admin Only) Update order status (Pending -> Shipped -> Delivered).
